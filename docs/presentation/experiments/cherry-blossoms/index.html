Experiment Notes

Finding: --cwd-context rw and shadow workspaces

An earlier run (demo5) used --cwd-context rw, which creates massgen_shadow_* temp directories for file isolation. This caused Codex to write SVGs to the shadow dir instead of its assigned workspace, making them appear "missing" from logs. The ChangeApplier successfully copied files back to the project root, but the logs workspace snapshot didn't capture them.

This run (demo6) omitted --cwd-context rw, and both agents' SVGs were properly persisted in snapshots, workspaces, and logs.
